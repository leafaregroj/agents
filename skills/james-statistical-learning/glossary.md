# Glossary — An Introduction to Statistical Learning (Python ed.)

**Backfitting** — fit a GAM one term at a time to partial residuals (Ch 7)
**Bagging** — average trees grown on bootstrap samples to reduce variance (Ch 8)
**BART** — Bayesian additive regression trees: perturb trees randomly and average after burn-in (Ch 8)
**Bayes classifier / error rate** — assigns the most probable class; its error rate 1 − E[maxⱼ Pr(Y=j|X)] is the lowest achievable (Ch 2)
**Benjamini–Hochberg (BH)** — controls FDR at q: reject p₍₁₎…p₍L₎ where L = max{j : p₍ⱼ₎ < qj/m} (Ch 13)
**Bias–variance trade-off** — expected test MSE = Var(f̂) + Bias(f̂)² + Var(ε) (Ch 2)
**Bonferroni** — controls FWER: reject if p < α/m (Ch 13)
**Boosting** — sequentially fit small trees to residuals, each shrunk by λ (Ch 8)
**Bootstrap** — resample n observations with replacement to estimate the variability of an estimator (Ch 5)
**C-index (Harrell's)** — concordance of predicted risk with observed survival order; the censored-data AUC (Ch 11)
**Censoring (right)** — observe min(T, C); the event time is unknown beyond C (Ch 11)
**Cost complexity pruning** — minimize RSS + α|T| over subtrees, choosing α by CV (Ch 8)
**Cox proportional hazards** — h(t|x) = h₀(t)·exp(xᵀβ), fit by partial likelihood (Ch 11)
**Cp / AIC / BIC / adjusted R²** — training-error criteria penalized for model size (Ch 6)
**Cross-entropy** — loss −Σ y log p̂, used for classification networks (Ch 10)
**Curse of dimensionality** — neighbors are far apart when p is large; noise features hurt (Ch 3, 6)
**Degrees of freedom (effective)** — a measure of flexibility; for smoothers, tr(S_λ) (Ch 2, 7)
**Dendrogram** — tree of hierarchical fusions; only the fusion height is meaningful (Ch 12)
**Double descent** — test error falls again past the interpolation threshold (Ch 10)
**Dropout** — randomly zero units at rate φ during training (Ch 10)
**Dummy variable** — 0/1 encoding of a qualitative predictor; K levels need K−1 dummies (Ch 3)
**False discovery rate (FDR)** — E(V/R), the expected fraction of rejections that are false (Ch 13)
**Family-wise error rate (FWER)** — Pr(V ≥ 1), the chance of at least one false rejection (Ch 13)
**F-statistic** — tests whether all (or a subset of) coefficients are zero (Ch 3)
**GAM** — generalized additive model, Σfⱼ(Xⱼ) (Ch 7)
**Gini index / entropy** — node-impurity measures for classification trees (Ch 8)
**GLM** — generalized linear model with link function; includes logistic and Poisson regression (Ch 4)
**Hazard function** — instantaneous event rate h(t) = f(t)/S(t) (Ch 11)
**Hierarchical principle** — keep main effects when their interaction is included (Ch 3)
**Hinge loss** — max[0, 1 − y·f(x)]; the SVM's loss (Ch 9)
**Holm's method** — step-down FWER control, uniformly more powerful than Bonferroni (Ch 13)
**Interaction (synergy)** — one predictor's effect depends on another's value (Ch 3)
**Irreducible error** — Var(ε), the floor on test error (Ch 2)
**Kaplan–Meier** — product-limit estimate of S(t) under censoring (Ch 11)
**Kernel** — similarity function replacing the inner product (polynomial, radial) (Ch 9)
**K-fold CV** — split data into k folds; train on k−1 and validate on 1, rotating (Ch 5)
**K-means** — partitions observations into K clusters by minimizing within-cluster variation (Ch 12)
**KNN** — classify or predict from the K nearest training points (Ch 2, 3, 4)
**Lasso** — ℓ₁-penalized least squares; produces sparse models (Ch 6)
**LDA / QDA** — Gaussian generative classifiers with shared / class-specific covariance (Ch 4)
**Leverage (hᵢ)** — how unusual xᵢ is; the average is (p+1)/n (Ch 3)
**Linkage** — inter-cluster dissimilarity: complete, average, single, or centroid (Ch 12)
**Log-rank test** — compares survival curves between groups (Ch 11)
**LOOCV** — leave-one-out CV; exact shortcut for least squares via 1/(1−hᵢ) (Ch 5)
**Logistic regression** — models the log-odds as linear in X (Ch 4)
**LSTM / RNN** — recurrent networks for sequences that share weights across time steps (Ch 10)
**Matrix completion** — impute missing entries via an iterative low-rank (PCA) fit (Ch 12)
**Maximal margin classifier** — separating hyperplane farthest from the training points (Ch 9)
**Naive Bayes** — generative classifier assuming features are independent within each class (Ch 4)
**Natural spline** — regression spline constrained to be linear beyond the boundary knots (Ch 7)
**Out-of-bag (OOB) error** — test-error estimate from the ~1/3 of observations each tree didn't see (Ch 8)
**Overfitting** — fitting the noise: low training error, high test error (Ch 2)
**PCA / PCR / PLS** — principal components / regression on them / supervised directions (Ch 6, 12)
**Permutation (re-sampling) null** — null distribution built by shuffling labels (Ch 13)
**Poisson regression** — GLM with log link for counts; assumes mean = variance (Ch 4)
**Prediction vs. confidence interval** — interval for an individual response vs. for its mean (Ch 3)
**PVE** — proportion of variance explained by a principal component (Ch 12)
**Random forest** — bagging that considers only m ≈ √p predictors at each split (Ch 8)
**ReLU** — max(0, z) activation (Ch 10)
**Ridge regression** — ℓ₂-penalized least squares; shrinks but keeps all predictors (Ch 6)
**ROC / AUC** — TPR vs FPR across thresholds; area under that curve (Ch 4, 9)
**RSE / R²** — residual standard error; fraction of variance explained (Ch 3)
**Smoothing spline** — minimizes RSS + λ∫g''(t)²dt (Ch 7)
**Softmax** — multinomial generalization of the logistic function (Ch 4, 10)
**Step function** — piecewise-constant basis from cutpoints (Ch 7)
**Support vector classifier / SVM** — soft-margin hyperplane with budget C; kernelized version (Ch 9)
**Support vectors** — observations on or inside the margin; they alone determine the fit (Ch 9)
**Tukey's method** — FWER control for all pairwise mean comparisons (Ch 13)
**Validation set approach** — single train/validation split; a noisy, upward-biased error estimate (Ch 5)
**VIF** — variance inflation factor 1/(1−R²ⱼ); flags collinearity (Ch 3)
