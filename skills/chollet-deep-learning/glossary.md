# Glossary — Deep Learning with Python (2nd ed.)

**Ablation study** — remove parts of a system to find where its performance comes from (Ch 9)
**Activation** — the non-linearity (relu, sigmoid, softmax) that keeps stacked layers from collapsing into one affine map (Ch 2, 4)
**Attention (query–key–value)** — weight values by the similarity between a query and keys; self-attention makes token representations context-aware (Ch 11)
**Backpropagation** — the chain rule applied to a computation graph to get gradients of the loss (Ch 2)
**Batch normalization** — normalize activations with batch statistics in training and a moving average at inference; freeze it when fine-tuning (Ch 9)
**Bag-of-words / N-grams** — text treated as an unordered set of tokens or short runs of tokens (Ch 11)
**Callback** — an object `fit()` calls at hook points: EarlyStopping, ModelCheckpoint, TensorBoard (Ch 7)
**Carry track** — the LSTM's "conveyor belt" that reinjects past information (Ch 10)
**Causal mask** — lower-triangular mask that blocks attention to future tokens (Ch 11, 12)
**Common-sense baseline** — the simplest non-ML answer (random guess, "tomorrow = today"); you must beat it (Ch 5, 6, 10)
**Concept drift** — production data changes over time, so model quality decays (Ch 6)
**Convolutional base** — the conv and pooling part of a pretrained convnet, reused for transfer learning (Ch 8)
**Crossentropy** — distance between probability distributions; the default classification loss (Ch 4)
**Data augmentation** — random, believable transforms of training inputs, inactive at inference (Ch 8)
**Depthwise separable convolution** — per-channel spatial conv then a 1×1 pointwise conv; far fewer parameters (Ch 9)
**Dropout** — randomly zero a layer's outputs during training (Ch 5)
**Embedding (word)** — a dense, learned vector whose geometry reflects meaning (Ch 11)
**Extreme generalization** — handling real novelty through abstraction; current DL cannot (Ch 5, 14)
**Feature extraction** — run a frozen pretrained base and train a new head on its outputs (Ch 8)
**Fine-tuning** — unfreeze the top layers of a pretrained base and train them jointly at a low learning rate (Ch 8)
**Functional API** — build models by calling layers on symbolic tensors; an inspectable graph of layers (Ch 7)
**GAN** — a generator and a discriminator trained adversarially (Ch 12)
**Grad-CAM** — class activation heatmap: last-conv feature maps weighted by pooled class-score gradients (Ch 9)
**GradientTape** — records TensorFlow ops so you can compute gradients (Ch 2, 3)
**Gram matrix** — correlations between a layer's feature maps, which capture style or texture (Ch 12)
**Hypothesis space** — the set of functions an architecture lets training search (Ch 1, 3, 9)
**Information leak** — tuning on validation results gradually overfits the validation set (Ch 5, 13)
**Interpolation** — the source of DL generalization: relating new points to nearby training points on the manifold (Ch 5)
**K-fold validation** — split into K parts and average the validation scores; use it when data is scarce (Ch 4, 5)
**KerasTuner** — hyperparameter search (`build_model(hp)`, BayesianOptimization) (Ch 13)
**Latent space** — a low-dimensional space a generative model samples from; concept vectors are directions in it (Ch 12)
**Manifold hypothesis** — natural data lies on a low-dimensional latent manifold in input space (Ch 5)
**Mixed precision** — float16 compute with float32 variables; keep softmax in float32 (Ch 13)
**Overfitting** — performance on held-out data falls while training performance keeps improving (Ch 2, 4, 5)
**Positional embedding** — a learned position vector added to each token embedding so a Transformer sees order (Ch 11)
**Progressive disclosure of complexity** — Keras's design principle: simple things simple, complex things possible (Ch 3, 7)
**Recurrent dropout** — a time-constant dropout mask on an RNN's recurrent units (Ch 10)
**Regularization** — methods that stop a model fitting training data perfectly (L1/L2, dropout, early stopping) (Ch 5)
**Residual connection** — add a block's input to its output so information and gradients flow through deep stacks (Ch 9)
**RNN / LSTM / GRU** — layers that loop over timesteps carrying state; GRU is the cheaper LSTM (Ch 10)
**Softmax temperature** — rescales a sampling distribution: low gives repetitive text, high gives random text (Ch 12)
**Spectrum of workflows** — from `Sequential` + `fit()` to subclassing and custom training loops (Ch 3, 7)
**Symbolic tensor** — `keras.Input` output: a shape and dtype with no data (Ch 7)
**Target leaking** — features that encode the target and won't exist in production (Ch 6)
**Tensor** — a container for numbers defined by rank, shape and dtype (Ch 2)
**TextVectorization** — the standardize → tokenize → index → encode layer; it runs on CPU (Ch 11)
**Transformer encoder / decoder** — self-attention + dense blocks with residual connections and LayerNormalization (Ch 11)
**Universal workflow of machine learning** — define the task → develop a model → deploy the model (Ch 6)
**VAE** — variational autoencoder: an encoder maps inputs to a distribution (mean, log-variance), and a KL term structures the latent space (Ch 12)
**Validation set** — held-out data for tuning; never tune on the test set (Ch 4, 5)
