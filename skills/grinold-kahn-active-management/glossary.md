# Glossary — Active Portfolio Management (Grinold & Kahn)

**Active beta (β_PA)** — portfolio beta minus 1. It is the instrument of benchmark timing (Ch 4, 19)
**Active management** — pursuit of returns above a specified benchmark (Ch 1)
**Active return** — portfolio return minus benchmark return (Ch 4)
**Active risk (ψ, tracking error)** — annualized std dev of active return. The median equity value is 4–5% (Ch 3, 5)
**Alpha (α)** — *expected* residual return. Ex post alpha is the realized residual (Ch 4, 5)
**Alpha scale** — std dev of alphas across assets ≈ volatility · IC (Ch 14)
**APT** — Arbitrage Pricing Theory. Expected excess returns are linear in factor exposures, f = X·m (Ch 7)
**Backcast** — using the historical average factor return as the factor forecast (Ch 7)
**Benchmark (bogey, normal)** — reference portfolio the manager seeks to beat. It is the principal's instruction set (Ch 1, 4)
**Benchmark-neutral alphas** — alphas adjusted so that α_B = 0, i.e. α − β·α_B (Ch 5, 14)
**Benchmark timing** — varying active beta to exploit Δf_B forecasts. It has low breadth (Ch 19)
**Beta (β)** — sensitivity of an asset or portfolio to the benchmark. Use forecast (risk-model) beta, not historical beta (Ch 2, 23)
**Breadth (BR)** — number of *independent* forecasts per year (Ch 6)
**Certainty equivalent return** — the risk-free return judged equal to a risky return: f − λσ² (Ch 4)
**Characteristic portfolio** — the minimum-risk portfolio with unit exposure to an attribute: h_a = V⁻¹a/(aᵀV⁻¹a) (Ch 2)
**Clean surplus** — b(t) = b(t−1) + e(t) − d(t). Basis of residual-income valuation (Ch 9)
**Common factor** — a source of return shared by many assets (industries, risk indices) (Ch 3)
**Competence** — knowing what you know, and using it optimally. It is the key assumption behind the Fundamental Law (Ch 6)
**Comparative valuation** — cross-sectional regression of price on attributes (Ch 9)
**Consensus expected returns** — CAPM returns β·μ_B. Holding the benchmark is optimal under them (Ch 2)
**Decay factor (γ, δ)** — monthly persistence of signal value. Half-life = ln 0.5 / ln γ (Ch 12, 13)
**Descriptor** — raw variable combined into a risk index (Ch 3)
**Dispersion** — spread of returns across accounts that share one strategy (Ch 14)
**Dividend discount model (DDM)** — price = PV of expected dividends. Constant growth: p = d/(y − g) (Ch 9)
**Event study** — regressing post-event standardized residual returns on event attributes (Ch 12)
**Exceptional return** — residual return plus benchmark-timing return (Ch 4)
**Exceptional benchmark return (Δf_B)** — forecast benchmark excess return minus its long-run consensus μ_B (Ch 4, 19)
**Excess return** — return minus the risk-free return (Ch 4)
**Factor portfolio** — the minimum-risk portfolio with unit exposure to one factor and zero exposure to the others (Ch 3, 12)
**Fundamental Law of Active Management** — IR = IC · √BR (Ch 6)
**Gini / Lorenz curve** — measures of benchmark capitalization concentration. They drive the long-only cost (Ch 15)
**Half-life** — time for a signal's IR (or a mispricing) to decay by half (Ch 8, 13)
**Humility principle** — the market may be right. Shrink your valuations toward the consensus (Ch 2, 9)
**Implementation shortfall** — paper-portfolio return minus realized return (Ch 16)
**Implied growth (g*)** — growth that makes the DDM price equal the market price (Ch 9)
**Information coefficient (IC)** — correlation of forecasts with realized residual returns. It measures skill (Ch 6, 10)
**Information horizon** — the decay profile of a signal's value over time (Ch 13)
**Information ratio (IR)** — α/ω, annualized expected residual return per unit of residual risk. It is both the figure of merit and the budget constraint (Ch 5)
**Information-efficient portfolio** — a portfolio that isolates a signal's return, with zero beta and zero factor exposure (Ch 12)
**Long-only constraint** — no negative holdings. It wastes negative information (Ch 15)
**Market impact** — price concession for trading size. It grows with √(trade/ADV) (Ch 16)
**Marginal contribution to active risk (MCAR)** — ∂ψ/∂h_n (Ch 3, 14)
**Marginal contribution to value added (MCVA)** — α − 2λψ·MCAR. At the optimum it is 0, or within the cost band (Ch 14)
**Naive / raw / refined forecast** — consensus / signal / consensus + conditional adjustment (Ch 10)
**Portfolio Q** — the fully invested portfolio with maximum Sharpe ratio. The CAPM says Q = M = B (Ch 2, 7)
**Portfolio A** — the characteristic portfolio of alpha (Ch 2, 5)
**Qualified (factor) model** — a model for which f = X·m holds for some m. Equivalent to Q being diversified (Ch 7)
**Residual return (θ)** — excess return minus β times benchmark excess return (Ch 2, 4)
**Residual risk (ω)** — std dev of residual return. Typically 20–35% for a single stock (Ch 3)
**Residual risk aversion (λ_R)** — penalty per unit residual variance: 0.05 aggressive, 0.10 moderate, 0.15 restrained (Ch 5)
**Residual frontier** — α = IR·ω. A straight line through the origin (Ch 5)
**Risk index** — a continuous common factor such as size, volatility, value or momentum (Ch 3)
**Score (z)** — standardized signal, with mean 0 and std 1 (Ch 10)
**Security market line** — expected excess return linear in beta (Ch 2)
**Sharpe ratio** — excess return / total risk (Ch 2, 17)
**Shrinkage factor (long/short)** — fraction of unconstrained IR that a long-only portfolio retains, ≈ 0.5 (Ch 15)
**Shrinkage factor (Bayesian IC)** — T·IC²/(1+T·IC²) (Ch 11)
**Specific return / risk** — return not explained by common factors, and its std dev (Ch 3)
**Spillover** — a forecast for one factor implies forecasts for correlated factors (Ch 11)
**Standard error** — std dev of an estimate. SE(mean) = σ/√T, so means are hard to estimate (Ch 23)
**Strategic / tactical asset allocation** — long-run policy mix / active deviations from it (Ch 18)
**Survivorship bias** — studying only surviving funds. It overstates returns and persistence (Ch 17, 20)
**t statistic** — estimate / standard error. |t| > 2 ≈ 5% chance of luck (Ch 12, 17)
**Time premium / risk premium** — risk-free rate / expected benchmark excess return μ_B (Ch 4)
**Turnover** — min(purchases, sales) as a fraction of the portfolio (Ch 16)
**Value added (VA)** — risk-adjusted active return: α_P − λ_R·ω_P². Optimum IR²/(4λ_R) (Ch 4, 5)
**Value multiples (υ)** — state-price deflators that make p = E{υ·cf}/(1+i_F) (Ch 8)
**Volatility** — annualized std dev of return (Ch 3)
